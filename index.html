Raw → Thickness Edge → Image Edge → Slope → Calculation → Judgment의 각 단계에서 입력·처리·출력을 확인할 수 있도록 정리했습니다.

처리 Flow

  1. Raw Data — Back / Top / Thick 취득 및 중첩 확인
  2. Thickness Edge — Threshold와 비교 차이로 후보 탐색
  3. Image Edge — Top / Back Y평균 밝기 → 후보 주변 Edge 탐색
  4. Slope — Edge 기준 구간별 기울기 계산 및 보정 준비
  5. Calculation — T/Max, T/Center, T/Sliding, %Sliding, Fat-Edge
  6. Judgment — Recipe / Spec과 결과 비교

핵심 공식

slope1=(p2−p1)/Angle1 · slope2=(p3−p2)/Angle2 · slope3=(p4−p3)/Angle3

T/Max = 0~20 mm 최대값
T/Center = 20~25 mm 평균값
T/Sliding = Edge 기준 지정 위치 값
%Sliding = (T/Sliding / T/Center) × 100
Fat-Edge = T/Max − T/Center

현재 구현과 추가 입력이 필요한 부분

현재 구현: 실제 CSV Raw/Thickness 탐색, 이미지 평균 밝기 프로파일, Image Edge 탐색, slope 계산, Total 계산/판정.
추가 입력 필요: PPT의 Foil thickness 및 기준면 파라미터가 있어야 Top / Back 개별 보정과 개별 %Sliding 판정을 임의 추정 없이 구현할 수 있습니다.
